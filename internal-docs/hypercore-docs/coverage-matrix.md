## Matrix rules applied

- Benchmark rows and latency observations were not reproduced as operations.
- Naming variants are grouped where no canonical Alchemy name exists.
- The `Hyperliquid exchange support` repository was not used as evidence for HyperCore public writes; it is a separate builder-code product with different scope.
- Every inventory family is represented above. Exact names within grouped families are retained to prevent an implicit scope decision.

## Draft documentation mapping

The `Public docs?` column remains `No` because it refers to production publication. The implementation draft now maps confirmed and draft surfaces into `docs/hypercore/`: WebSocket P0-P2 under `websocket/`, high-priority reads under `rest/`, block and batch methods under `json-rpc/`, StreamBlocks under `grpc/`, and historical surfaces under `historical-data/`. Canonical choices and aliases are recorded in [api-design-decisions.md](api-design-decisions.md).
