# Networks and endpoints

## Endpoint placeholders

- HTTP: `<HYPERCORE_HTTP_URL>`
- WebSocket: `<HYPERCORE_WEBSOCKET_URL>`
- gRPC: `<HYPERCORE_GRPC_HOST>`

## Networks
Every request is network-scoped by endpoint or an explicit future network selector. The initial network matrix and network names require engineering validation.

## Data API endpoints

Data products use separate placeholder endpoints until engineering approves production hostnames. See [Data API networks and endpoints](../../../data/hypercore/networks-and-endpoints.mdx).
