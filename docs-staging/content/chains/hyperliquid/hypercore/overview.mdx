# HyperCore Chain API

Use the HyperCore Chain API for protocol-level reads, raw blocks, block-oriented JSON-RPC methods, and chain-level streaming. It is the proposed Chain tab entry point for Hyperliquid's native exchange engine.

For purpose-built market streams, enriched wallet and account data, and historical query products, see [the HyperCore Data API](../../../data/hypercore/overview.mdx).

## Included surfaces

- Protocol and network concepts
- Block identifiers, block data, and finality
- `hl_*` JSON-RPC block and batch methods
- StreamBlocks as an MDX gRPC reference
- Chain-level checkpointing and backfill
