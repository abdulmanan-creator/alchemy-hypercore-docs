> **Draft API contract**
> Coverage, retention, and freshness are not yet production commitments. This page defines the metadata contract that every released dataset and query method must publish.

# Historical availability

## Required metadata
Each surface must state earliest available timestamp or height, retention, freshness target, query bounds, late-data policy, correction policy, and schema version. Until then, consumers must treat availability as draft.
