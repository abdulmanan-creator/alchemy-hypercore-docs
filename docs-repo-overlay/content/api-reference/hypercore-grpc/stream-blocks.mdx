# StreamBlocks

## intended RPC
`rpc StreamBlocks(StreamBlocksRequest) returns (stream BlockEnvelope);`

`StreamBlocksRequest` proposes `start_block_height`, optional `cursor`, and an `include` list for commands, actions, events, and fills.

## intended message
> The values below illustrate the intended request shape.

```proto
message BlockEnvelope {
  string cursor = 1;
  uint64 block_height = 2;
  int64 block_time_ms = 3;
  bool is_final = 4;
  BlockData block = 5;
}
```

## Recovery
Persist the last fully processed height and cursor. On reconnect, request the next height; use `hl_getBatchBlocks` to repair any reported gap.

## Recovery

Use [streaming plus backfill recovery](../../../data/hypercore/guides/combine-streaming-with-backfill.mdx) to reconcile a missed range.
