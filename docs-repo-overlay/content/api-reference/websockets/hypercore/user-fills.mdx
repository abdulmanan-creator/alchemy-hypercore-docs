# userFills stream

## Subscribe
> The values below illustrate the intended request shape.

```json
{
  "jsonrpc": "2.0",
  "id": 1,
  "method": "subscribe",
  "subscription": {
    "type": "userFills",
    "filters": { "users": ["0x1111111111111111111111111111111111111111"] }
  }
}
```

## Acknowledgement
```json
{
  "jsonrpc": "2.0",
  "id": 1,
  "result": { "subscriptionId": "sub_01", "type": "userFills" }
}
```

## Event envelope

```json
{
  "jsonrpc": "2.0",
  "method": "subscription",
  "params": {
    "subscriptionId": "sub_01",
    "type": "userFills",
    "blockHeight": 123456,
    "blockTime": 1780000000000,
    "data": { "fills": [{"user":"0x1111111111111111111111111111111111111111","market":"BTC","price":"100000.0","size":"0.01","side":"buy","fee":"0.20","tradeId":"trade_01","time":1780000000000}] }
  }
}
```

## Unsubscribe
```json
{
  "jsonrpc": "2.0",
  "id": 2,
  "method": "unsubscribe",
  "params": { "subscriptionId": "sub_01" }
}
```
## Resume

To resume a stream, use `resumeFromCheckpoint`. `cursor` is accepted as an alias for existing client code. The checkpoint is opaque: clients store and return it unmodified, and its format may change.
