# l2BookDiff stream

For the corresponding gRPC diff stream, see [StreamL2BookDiff](../../hypercore-grpc/stream-l2-book-diff.mdx). [l2Book](l2-book.mdx) is the snapshot representation.

## Subscribe
> The values below illustrate the intended request shape.

```json
{
  "jsonrpc": "2.0",
  "id": 1,
  "method": "subscribe",
  "subscription": {
    "type": "l2BookDiff",
    "filters": { "markets": ["BTC"] }
  }
}
```

## Acknowledgement
```json
{
  "jsonrpc": "2.0",
  "id": 1,
  "result": { "subscriptionId": "sub_01", "type": "l2BookDiff" }
}
```

## Event envelope

```json
{
  "jsonrpc": "2.0",
  "method": "subscription",
  "params": {
    "subscriptionId": "sub_01",
    "type": "l2BookDiff",
    "blockHeight": 123456,
    "blockTime": 1780000000000,
    "data": { "market": "BTC", "changes": [{"side":"bid","price":"100000.0","size":"1.50","orderCount":4}], "isSnapshot": false }
  }
}
```

## Unsubscribe
```json
{
  "jsonrpc": "2.0",
  "id": 2,
  "method": "unsubscribe",
  "params": { "subscriptionId": "sub_01" }
}
```
## Resume

To resume a stream, use `resumeFromCheckpoint`. `cursor` is accepted as an alias for existing client code. The checkpoint is opaque: clients store and return it unmodified, and its format may change.
