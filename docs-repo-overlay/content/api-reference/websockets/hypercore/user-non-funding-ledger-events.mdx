# userNonFundingLedgerEvents stream

## Subscribe
> The values below illustrate the intended request shape.

```json
{
  "jsonrpc": "2.0",
  "id": 1,
  "method": "subscribe",
  "subscription": {
    "type": "userNonFundingLedgerEvents",
    "filters": { "users": ["0x1111111111111111111111111111111111111111"] }
  }
}
```

## Acknowledgement
```json
{
  "jsonrpc": "2.0",
  "id": 1,
  "result": { "subscriptionId": "sub_01", "type": "userNonFundingLedgerEvents" }
}
```

## Event envelope

```json
{
  "jsonrpc": "2.0",
  "method": "subscription",
  "params": {
    "subscriptionId": "sub_01",
    "type": "userNonFundingLedgerEvents",
    "blockHeight": 123456,
    "blockTime": 1780000000000,
    "data": { "user":"0x1111111111111111111111111111111111111111", "eventType":"deposit", "asset":"USDC", "amount":"100.00", "time":1780000000000 }
  }
}
```

## Unsubscribe
```json
{
  "jsonrpc": "2.0",
  "id": 2,
  "method": "unsubscribe",
  "params": { "subscriptionId": "sub_01" }
}
```
## Resume

To resume a stream, use `resumeFromCheckpoint`. `cursor` is accepted as an alias for existing client code. The checkpoint is opaque: clients store and return it unmodified, and its format may change.
