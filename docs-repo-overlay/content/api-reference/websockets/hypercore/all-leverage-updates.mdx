# allLeverageUpdates stream

Carries leverage-setting updates across the available stream scope.

## Subscribe

```json
{
  "jsonrpc": "2.0",
  "id": 1,
  "method": "subscribe",
  "subscription": {
    "type": "allLeverageUpdates"
  }
}
```
## Resume

To resume a stream, use `resumeFromCheckpoint`. `cursor` is accepted as an alias for existing client code. The checkpoint is opaque: clients store and return it unmodified, and its format may change.
