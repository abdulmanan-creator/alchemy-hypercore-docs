# bbo stream

For the corresponding gRPC stream, see [StreamBboBook](../../hypercore-grpc/stream-bbo-book.mdx).

## Subscribe
> The values below illustrate the intended request shape.

```json
{
  "jsonrpc": "2.0",
  "id": 1,
  "method": "subscribe",
  "subscription": {
    "type": "bbo",
    "filters": { "markets": ["BTC"] }
  }
}
```

## Acknowledgement
```json
{
  "jsonrpc": "2.0",
  "id": 1,
  "result": { "subscriptionId": "sub_01", "type": "bbo" }
}
```

## Event envelope

```json
{
  "jsonrpc": "2.0",
  "method": "subscription",
  "params": {
    "subscriptionId": "sub_01",
    "type": "bbo",
    "blockHeight": 123456,
    "blockTime": 1780000000000,
    "data": { "market":"BTC", "bid":{"price":"100000.0","size":"1.25"}, "ask":{"price":"100001.0","size":"0.80"} }
  }
}
```

## Unsubscribe
```json
{
  "jsonrpc": "2.0",
  "id": 2,
  "method": "unsubscribe",
  "params": { "subscriptionId": "sub_01" }
}
```
## Resume

To resume a stream, use `resumeFromCheckpoint`. `cursor` is accepted as an alias for existing client code. The checkpoint is opaque: clients store and return it unmodified, and its format may change.
