# userOrderUpdates stream

## Subscribe
> The values below illustrate the intended request shape.

```json
{
  "jsonrpc": "2.0",
  "id": 1,
  "method": "subscribe",
  "subscription": {
    "type": "userOrderUpdates",
    "filters": { "users": ["0x1111111111111111111111111111111111111111"] }
  }
}
```

## Acknowledgement
```json
{
  "jsonrpc": "2.0",
  "id": 1,
  "result": { "subscriptionId": "sub_01", "type": "userOrderUpdates" }
}
```

## Event envelope

```json
{
  "jsonrpc": "2.0",
  "method": "subscription",
  "params": {
    "subscriptionId": "sub_01",
    "type": "userOrderUpdates",
    "blockHeight": 123456,
    "blockTime": 1780000000000,
    "data": { "orders": [{"user":"0x1111111111111111111111111111111111111111","orderId":"12345","market":"BTC","side":"buy","limitPrice":"100000.0","size":"0.10","status":"open","filledSize":"0"}] }
  }
}
```

## Unsubscribe
```json
{
  "jsonrpc": "2.0",
  "id": 2,
  "method": "unsubscribe",
  "params": { "subscriptionId": "sub_01" }
}
```
## Resume

To resume a stream, use `resumeFromCheckpoint`. `cursor` is accepted as an alias for existing client code. The checkpoint is opaque: clients store and return it unmodified, and its format may change.
