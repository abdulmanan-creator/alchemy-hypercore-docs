# l4BookUpdates stream

For the corresponding gRPC update stream, see [StreamL4BookUpdates](../../hypercore-grpc/stream-l4-book-updates.mdx).

## Subscribe
> The values below illustrate the intended request shape.

```json
{
  "jsonrpc": "2.0",
  "id": 1,
  "method": "subscribe",
  "subscription": {
    "type": "l4BookUpdates",
    "filters": { "markets": ["BTC"] }
  }
}
```

## Acknowledgement
```json
{
  "jsonrpc": "2.0",
  "id": 1,
  "result": { "subscriptionId": "sub_01", "type": "l4BookUpdates" }
}
```

## Event envelope

```json
{
  "jsonrpc": "2.0",
  "method": "subscription",
  "params": {
    "subscriptionId": "sub_01",
    "type": "l4BookUpdates",
    "blockHeight": 123456,
    "blockTime": 1780000000000,
    "data": { "market":"BTC", "orders":[{"orderId":"12345","side":"bid","price":"100000.0","size":"0.10","action":"upsert"}] }
  }
}
```

## Unsubscribe
```json
{
  "jsonrpc": "2.0",
  "id": 2,
  "method": "unsubscribe",
  "params": { "subscriptionId": "sub_01" }
}
```
## Resume

To resume a stream, use `resumeFromCheckpoint`. `cursor` is accepted as an alias for existing client code. The checkpoint is opaque: clients store and return it unmodified, and its format may change.
