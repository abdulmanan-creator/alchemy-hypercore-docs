# l2Book stream

For the corresponding gRPC snapshot stream, see [StreamL2Book](../../hypercore-grpc/stream-l2-book.mdx). For the diff representation, see [l2BookDiff](l2-book-diff.mdx).

## Subscribe
> The values below illustrate the intended request shape.

```json
{
  "jsonrpc": "2.0",
  "id": 1,
  "method": "subscribe",
  "subscription": {
    "type": "l2Book",
    "filters": { "markets": ["BTC"] }
  }
}
```

## Acknowledgement
```json
{
  "jsonrpc": "2.0",
  "id": 1,
  "result": { "subscriptionId": "sub_01", "type": "l2Book" }
}
```

## Event envelope

```json
{
  "jsonrpc": "2.0",
  "method": "subscription",
  "params": {
    "subscriptionId": "sub_01",
    "type": "l2Book",
    "blockHeight": 123456,
    "blockTime": 1780000000000,
    "data": { "market": "BTC", "levels": [[{"price":"100000.0","size":"1.25","orderCount":3}], [{"price":"100001.0","size":"0.80","orderCount":2}]], "isSnapshot": true }
  }
}
```

## Unsubscribe
```json
{
  "jsonrpc": "2.0",
  "id": 2,
  "method": "unsubscribe",
  "params": { "subscriptionId": "sub_01" }
}
```
## Resume

To resume a stream, use `resumeFromCheckpoint`. `cursor` is accepted as an alias for existing client code. The checkpoint is opaque: clients store and return it unmodified, and its format may change.
