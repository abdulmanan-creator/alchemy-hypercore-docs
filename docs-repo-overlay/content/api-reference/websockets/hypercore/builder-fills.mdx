# builderFills stream

## Subscribe
> The values below illustrate the intended request shape.

```json
{
  "jsonrpc": "2.0",
  "id": 1,
  "method": "subscribe",
  "subscription": {
    "type": "builderFills",
    "filters": { "builders": ["0x2222222222222222222222222222222222222222"] }
  }
}
```

## Acknowledgement
```json
{
  "jsonrpc": "2.0",
  "id": 1,
  "result": { "subscriptionId": "sub_01", "type": "builderFills" }
}
```

## Event envelope

```json
{
  "jsonrpc": "2.0",
  "method": "subscription",
  "params": {
    "subscriptionId": "sub_01",
    "type": "builderFills",
    "blockHeight": 123456,
    "blockTime": 1780000000000,
    "data": { "fills": [{"builder":"0x2222222222222222222222222222222222222222","market":"BTC","price":"100000.0","size":"0.01","tradeId":"trade_03"}] }
  }
}
```

## Unsubscribe
```json
{
  "jsonrpc": "2.0",
  "id": 2,
  "method": "unsubscribe",
  "params": { "subscriptionId": "sub_01" }
}
```
## Resume

To resume a stream, use `resumeFromCheckpoint`. `cursor` is accepted as an alias for existing client code. The checkpoint is opaque: clients store and return it unmodified, and its format may change.
