# tpslUpdates stream

For the corresponding gRPC stream, see [StreamTpslUpdates](../../hypercore-grpc/stream-tpsl-updates.mdx).

## Subscribe
> The values below illustrate the intended request shape.

```json
{
  "jsonrpc": "2.0",
  "id": 1,
  "method": "subscribe",
  "subscription": {
    "type": "tpslUpdates",
    "filters": { "users": ["0x1111111111111111111111111111111111111111"] }
  }
}
```

## Acknowledgement
```json
{
  "jsonrpc": "2.0",
  "id": 1,
  "result": { "subscriptionId": "sub_01", "type": "tpslUpdates" }
}
```

## Event envelope

```json
{
  "jsonrpc": "2.0",
  "method": "subscription",
  "params": {
    "subscriptionId": "sub_01",
    "type": "tpslUpdates",
    "blockHeight": 123456,
    "blockTime": 1780000000000,
    "data": { "user":"0x1111111111111111111111111111111111111111", "orderId":"12345", "triggerType":"stopLoss", "triggerPrice":"99000.0", "status":"triggered" }
  }
}
```

## Unsubscribe
```json
{
  "jsonrpc": "2.0",
  "id": 2,
  "method": "unsubscribe",
  "params": { "subscriptionId": "sub_01" }
}
```
## Resume

To resume a stream, use `resumeFromCheckpoint`. `cursor` is accepted as an alias for existing client code. The checkpoint is opaque: clients store and return it unmodified, and its format may change.
