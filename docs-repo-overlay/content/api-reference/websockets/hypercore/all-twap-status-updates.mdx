# allTwapStatusUpdates stream

## Subscribe
> The values below illustrate the intended request shape.

```json
{
  "jsonrpc": "2.0",
  "id": 1,
  "method": "subscribe",
  "subscription": {
    "type": "allTwapStatusUpdates",
    "filters": { "markets": ["BTC"] },
    "cursor": "optional-cursor"
  }
}
```


## Acknowledgement
```json
{
  "jsonrpc": "2.0",
  "id": 1,
  "result": { "subscriptionId": "sub_01", "type": "allTwapStatusUpdates" }
}
```


## Event envelope

```json
{
  "jsonrpc": "2.0",
  "method": "subscription",
  "params": {
    "subscriptionId": "sub_01",
    "type": "allTwapStatusUpdates",
    "cursor": "cursor_000001",
    "blockHeight": 123456,
    "blockTime": 1780000000000,
    "data": { "twapId":"twap_01", "market":"BTC", "status":"active", "executedSize":"0.20", "remainingSize":"0.80" }
  }
}
```



## Unsubscribe
```json
{
  "jsonrpc": "2.0",
  "id": 2,
  "method": "unsubscribe",
  "params": { "subscriptionId": "sub_01" }
}
```
