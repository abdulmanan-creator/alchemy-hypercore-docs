# Delegator history

Returns a user's delegation, deposit, and withdrawal history.

## Request

`POST /{apiKey}/info`

| Parameter | Type   | Required | Description                    |
| --------- | ------ | -------- | ------------------------------ |
| `type`    | string | Yes      | Selects `delegatorHistory`.    |
| `user`    | string | Yes      | Master or sub-account address. |

```json
{
  "type": "delegatorHistory",
  "user": "0x0000000000000000000000000000000000000000"
}
```

## Response fields

| Field                                | Type   | Description                           |
| ------------------------------------ | ------ | ------------------------------------- |
| `data[]`                             | varies | Response entries.                     |
| `data[].time`                        | varies | `time` value in the response.         |
| `data[].hash`                        | varies | `hash` value in the response.         |
| `data[].delta`                       | varies | Activity-specific delta.              |
| `data[].delta.delegate`              | varies | `delegate` value in the response.     |
| `data[].delta.delegate.validator`    | varies | Validator address.                    |
| `data[].delta.delegate.amount`       | varies | Delegated amount.                     |
| `data[].delta.delegate.isUndelegate` | varies | `isUndelegate` value in the response. |

## Response example

```json
[
  {
    "time": 1735380381353,
    "hash": "0x55492465cb523f90815a041a226ba90147008d4b221a24ae8dc35a0dbede4ea4",
    "delta": {
      "delegate": {
        "validator": "0x5ac99df645f3414876c816caa18b2d234024b487",
        "amount": "10000.0",
        "isUndelegate": false
      }
    }
  }
]
```
