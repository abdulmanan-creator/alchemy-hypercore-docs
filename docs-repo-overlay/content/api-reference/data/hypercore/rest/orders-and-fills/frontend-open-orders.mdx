# Frontend open orders

Returns open orders with trigger, reduce-only, and order-type details used by trading interfaces.

## Request

`POST /{apiKey}/info`

| Parameter | Type   | Required | Description                                           |
| --------- | ------ | -------- | ----------------------------------------------------- |
| `type`    | string | Yes      | Selects `frontendOpenOrders`.                         |
| `user`    | string | Yes      | Master or sub-account address.                        |
| `dex`     | string | No       | Perpetual DEX name; omit for the first perpetual DEX. |

```json
{
  "type": "frontendOpenOrders",
  "user": "0x0000000000000000000000000000000000000000",
  "dex": ""
}
```

## Response fields

| Field                     | Type   | Description                               |
| ------------------------- | ------ | ----------------------------------------- |
| `data[]`                  | varies | Response object.                          |
| `data[].coin`             | varies | Market identifier.                        |
| `data[].isPositionTpsl`   | varies | `isPositionTpsl` value in the response.   |
| `data[].isTrigger`        | varies | `isTrigger` value in the response.        |
| `data[].limitPx`          | varies | `limitPx` value in the response.          |
| `data[].oid`              | varies | Order identifier.                         |
| `data[].orderType`        | varies | `orderType` value in the response.        |
| `data[].origSz`           | varies | `origSz` value in the response.           |
| `data[].reduceOnly`       | varies | `reduceOnly` value in the response.       |
| `data[].side`             | varies | Order side.                               |
| `data[].sz`               | varies | Size.                                     |
| `data[].timestamp`        | varies | Timestamp in milliseconds.                |
| `data[].triggerCondition` | varies | `triggerCondition` value in the response. |
| `data[].triggerPx`        | varies | `triggerPx` value in the response.        |
