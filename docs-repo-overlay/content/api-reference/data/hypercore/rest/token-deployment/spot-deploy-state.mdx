# Spot deployment state

Returns the caller's spot-token deployment states and the current deployment auction.

## Request

`POST /{apiKey}/info`

| Parameter | Type   | Required | Description                    |
| --------- | ------ | -------- | ------------------------------ |
| `type`    | string | Yes      | Selects `spotDeployState`.     |
| `user`    | string | Yes      | Master or sub-account address. |

```json
{
  "type": "spotDeployState",
  "user": "0x0000000000000000000000000000000000000000"
}
```

## Response fields

| Field                                   | Type           | Description                                                  |
| --------------------------------------- | -------------- | ------------------------------------------------------------ |
| `states[]`                              | array          | Deployment-state entries.                                    |
| `states[].token`                        | integer        | Token index.                                                 |
| `states[].spec`                         | object         | `spec` value in the response.                                |
| `states[].spec.name`                    | string         | Name.                                                        |
| `states[].spec.szDecimals`              | integer        | `szDecimals` value in the response.                          |
| `states[].spec.weiDecimals`             | integer        | `weiDecimals` value in the response.                         |
| `states[].fullName`                     | string \| null | Full token name, or `null` when not supplied.                |
| `states[].spots`                        | array          | `spots` value in the response.                               |
| `states[].maxSupply`                    | integer        | `maxSupply` value in the response.                           |
| `states[].hyperliquidityGenesisBalance` | string         | `hyperliquidityGenesisBalance` value in the response.        |
| `states[].totalGenesisBalanceWei`       | string         | `totalGenesisBalanceWei` value in the response.              |
| `states[].userGenesisBalances`          | array          | `userGenesisBalances` value in the response.                 |
| `states[].existingTokenGenesisBalances` | array          | `existingTokenGenesisBalances` value in the response.        |
| `gasAuction`                            | object         | `gasAuction` value in the response.                          |
| `gasAuction.startTimeSeconds`           | integer        | `startTimeSeconds` value in the response.                    |
| `gasAuction.durationSeconds`            | integer        | `durationSeconds` value in the response.                     |
| `gasAuction.startGas`                   | string         | `startGas` value in the response.                            |
| `gasAuction.currentGas`                 | string \| null | Current auction gas price, or `null` before it is available. |
| `gasAuction.endGas`                     | string \| null | Auction end gas price, or `null` while the auction is open.  |

## Response example

```json
{
  "states": [
    {
      "token": 150,
      "spec": { "name": "HYPE", "szDecimals": 2, "weiDecimals": 8 },
      "fullName": "Hyperliquid",
      "spots": [107],
      "maxSupply": 1000000000
    }
  ],
  "gasAuction": {
    "startTimeSeconds": 1733929200,
    "durationSeconds": 111600,
    "startGas": "181305.90046",
    "currentGas": null,
    "endGas": "181291.247358"
  }
}
```
