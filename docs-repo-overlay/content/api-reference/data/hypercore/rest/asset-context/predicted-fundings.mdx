# Predicted fundings

Returns predicted funding rates and scheduled funding times for the first perpetual DEX.

## Request

`POST /{apiKey}/info`

| Parameter | Type   | Required | Description                  |
| --------- | ------ | -------- | ---------------------------- |
| `type`    | string | Yes      | Selects `predictedFundings`. |

```json
{
  "type": "predictedFundings"
}
```

## Response fields

| Field                             | Type           | Description                                               |
| --------------------------------- | -------------- | --------------------------------------------------------- |
| `[]`                              | array          | Market funding-prediction entries.                        |
| `[][0]`                           | string         | Market identifier at tuple index 0.                       |
| `[][1]`                           | array          | Venue-funding entries at tuple index 1.                   |
| `[][1][][0]`                      | string \| null | Venue identifier, or `null` when that venue has no entry. |
| `[][1][][1]`                      | object         | Funding prediction for the venue.                         |
| `[][1][][1].fundingRate`          | string         | Funding rate.                                             |
| `[][1][][1].nextFundingTime`      | integer        | `nextFundingTime` value in the response.                  |
| `[][1][][1].fundingIntervalHours` | integer        | `fundingIntervalHours` value in the response.             |

## Response example

```json
[
  [
    "AVAX",
    [
      [
        "HlPerp",
        { "fundingRate": "0.0000125", "nextFundingTime": 1733958000000 }
      ]
    ]
  ]
]
```
