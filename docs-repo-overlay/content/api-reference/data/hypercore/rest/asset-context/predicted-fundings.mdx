# Predicted fundings

Predicted funding values by market and venue.

## Request

`POST /{apiKey}/info`

| Parameter             | Type   | Description         |
| --------------------- | ------ | ------------------- |
| `type`                | string | `predictedFundings` |
| Additional parameters | varies | —                   |

```json
{
  "type": "predictedFundings"
}
```

## Response fields

| Field    | Description                        |
| -------- | ---------------------------------- |
| Response | [coin, [[venue, funding data], …]] |
