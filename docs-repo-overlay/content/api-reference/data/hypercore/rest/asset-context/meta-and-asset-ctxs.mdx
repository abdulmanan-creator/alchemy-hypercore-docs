# Perpetual metadata and asset contexts

Returns perpetual metadata and aligned live market contexts; use it to read the current oracle price alongside mark and mid prices.

## Request

`POST /{apiKey}/info`

| Parameter | Type   | Required | Description                                           |
| --------- | ------ | -------- | ----------------------------------------------------- |
| `type`    | string | Yes      | Selects `metaAndAssetCtxs`.                           |
| `dex`     | string | No       | Perpetual DEX name; omit for the first perpetual DEX. |

```json
{
  "type": "metaAndAssetCtxs",
  "dex": ""
}
```

## Response fields

| Field                            | Type   | Description                              |
| -------------------------------- | ------ | ---------------------------------------- |
| `data[0]`                        | varies | `data[0]` value in the response.         |
| `data[0].universe[]`             | varies | `universe` value in the response.        |
| `data[0].universe[].name`        | varies | Name.                                    |
| `data[0].universe[].szDecimals`  | varies | `szDecimals` value in the response.      |
| `data[0].universe[].maxLeverage` | varies | `maxLeverage` value in the response.     |
| `data[0].marginTables`           | varies | `marginTables` value in the response.    |
| `data[0].collateralToken`        | varies | `collateralToken` value in the response. |
| `data[1]`                        | varies | `data[1]` value in the response.         |
| `data[1][].dayNtlVlm`            | varies | `dayNtlVlm` value in the response.       |
| `data[1][].funding`              | varies | `funding` value in the response.         |
| `data[1][].impactPxs`            | varies | `impactPxs` value in the response.       |
| `data[1][].markPx`               | varies | Current mark price.                      |
| `data[1][].midPx`                | varies | Current mid price.                       |
| `data[1][].openInterest`         | varies | `openInterest` value in the response.    |
| `data[1][].oraclePx`             | varies | Current oracle price.                    |
| `data[1][].premium`              | varies | `premium` value in the response.         |
| `data[1][].prevDayPx`            | varies | `prevDayPx` value in the response.       |
