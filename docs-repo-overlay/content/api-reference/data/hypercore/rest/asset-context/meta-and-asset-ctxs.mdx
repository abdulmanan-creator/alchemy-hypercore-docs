# Perpetual metadata and asset contexts

Returns perpetual metadata and aligned live market contexts; use it to read the current oracle price alongside mark and mid prices.

## Request

`POST /{apiKey}/info`

| Parameter | Type   | Required | Description                                           |
| --------- | ------ | -------- | ----------------------------------------------------- |
| `type`    | string | Yes      | Selects `metaAndAssetCtxs`.                           |
| `dex`     | string | No       | Perpetual DEX name; omit for the first perpetual DEX. |

```json
{
  "type": "metaAndAssetCtxs",
  "dex": ""
}
```

## Response fields

| Field                        | Type    | Description                                   |
| ---------------------------- | ------- | --------------------------------------------- |
| `[0]`                        | object  | Metadata object at tuple index 0.             |
| `[0].universe[]`             | array   | `universe` value in the response.             |
| `[0].universe[].name`        | string  | Name.                                         |
| `[0].universe[].szDecimals`  | integer | `szDecimals` value in the response.           |
| `[0].universe[].maxLeverage` | integer | `maxLeverage` value in the response.          |
| `[0].marginTables`           | array   | `marginTables` value in the response.         |
| `[0].collateralToken`        | integer | `collateralToken` value in the response.      |
| `[1]`                        | array   | Aligned asset-context array at tuple index 1. |
| `[1][].dayNtlVlm`            | string  | `dayNtlVlm` value in the response.            |
| `[1][].funding`              | string  | `funding` value in the response.              |
| `[1][].impactPxs`            | array   | `impactPxs` value in the response.            |
| `[1][].markPx`               | string  | Current mark price.                           |
| `[1][].midPx`                | string  | Current mid price.                            |
| `[1][].openInterest`         | string  | `openInterest` value in the response.         |
| `[1][].oraclePx`             | string  | Current oracle price.                         |
| `[1][].premium`              | string  | `premium` value in the response.              |
| `[1][].prevDayPx`            | string  | `prevDayPx` value in the response.            |
