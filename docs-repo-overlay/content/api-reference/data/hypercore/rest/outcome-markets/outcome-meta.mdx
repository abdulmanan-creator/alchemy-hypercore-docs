# Outcome metadata

Returns registered outcome-market specifications and questions.

## Request

`POST /{apiKey}/info`

| Parameter | Type   | Required | Description            |
| --------- | ------ | -------- | ---------------------- |
| `type`    | string | Yes      | Selects `outcomeMeta`. |

```json
{
  "type": "outcomeMeta"
}
```

## Response fields

| Field                         | Type    | Description                        |
| ----------------------------- | ------- | ---------------------------------- |
| `outcomes[]`                  | array   | `outcomes` value in the response.  |
| `outcomes[].outcome`          | integer | `outcome` value in the response.   |
| `outcomes[].name`             | string  | Name.                              |
| `outcomes[].description`      | string  | Description.                       |
| `outcomes[].sideSpecs[]`      | array   | `sideSpecs` value in the response. |
| `outcomes[].sideSpecs[].name` | string  | Name.                              |
| `questions[]`                 | array   | `questions` value in the response. |
| `deployers`                   | array   | `deployers` value in the response. |
| `feeScale`                    | integer | `feeScale` value in the response.  |

## Response example

```json
{
  "outcomes": [
    {
      "outcome": 123,
      "name": "Recurring",
      "description": "class:priceBinary|underlying:HYPE|expiry:20260310-1100|targetPrice:34.5|period:3m",
      "sideSpecs": [{ "name": "Yes" }, { "name": "No" }]
    }
  ],
  "questions": [],
  "deployers": [],
  "feeScale": 0
}
```
