# Settled outcome

Settlement data for one outcome.

## Request

`POST /{apiKey}/info`

| Parameter             | Type   | Description      |
| --------------------- | ------ | ---------------- |
| `type`                | string | `settledOutcome` |
| Additional parameters | varies | outcome          |

```json
{
  "type": "settledOutcome"
}
```

## Response fields

| Field    | Description                   |
| -------- | ----------------------------- |
| Response | spec, settleFraction, details |
