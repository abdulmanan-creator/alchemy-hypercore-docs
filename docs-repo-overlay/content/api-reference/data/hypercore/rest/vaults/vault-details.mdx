# Vault details

Returns a vault's configuration, performance history, and follower state.

## Request

`POST /{apiKey}/info`

| Parameter      | Type   | Required | Description                    |
| -------------- | ------ | -------- | ------------------------------ |
| `type`         | string | Yes      | Selects `vaultDetails`.        |
| `vaultAddress` | string | Yes      | Vault address.                 |
| `user`         | string | Yes      | Master or sub-account address. |

```json
{
  "type": "vaultDetails",
  "vaultAddress": "0xdfc24b077bc1425ad1dea75bcb6f8158e10df303",
  "user": "0x0000000000000000000000000000000000000000"
}
```

## Response fields

| Field                                | Type           | Description                                                         |
| ------------------------------------ | -------------- | ------------------------------------------------------------------- |
| `name`                               | string         | Name.                                                               |
| `vaultAddress`                       | string         | `vaultAddress` value in the response.                               |
| `leader`                             | string         | Vault leader address.                                               |
| `description`                        | string         | Description.                                                        |
| `portfolio`                          | array          | Performance history by interval.                                    |
| `portfolio[][0]`                     | string         | `portfolio[][0]` value in the response.                             |
| `portfolio[][1].accountValueHistory` | array          | `accountValueHistory` value in the response.                        |
| `portfolio[][1].pnlHistory`          | array          | `pnlHistory` value in the response.                                 |
| `portfolio[][1].vlm`                 | string         | `vlm` value in the response.                                        |
| `apr`                                | number         | Annualized return.                                                  |
| `followerState`                      | object \| null | Follower state for the requesting user, or `null` when none exists. |
| `leaderFraction`                     | number         | `leaderFraction` value in the response.                             |
| `leaderCommission`                   | number         | `leaderCommission` value in the response.                           |
| `followers[]`                        | array          | Vault followers.                                                    |
| `followers[].user`                   | string         | `user` value in the response.                                       |
| `followers[].vaultEquity`            | string         | `vaultEquity` value in the response.                                |
| `followers[].pnl`                    | string         | `pnl` value in the response.                                        |
| `followers[].allTimePnl`             | string         | `allTimePnl` value in the response.                                 |
| `followers[].daysFollowing`          | integer        | `daysFollowing` value in the response.                              |
| `followers[].vaultEntryTime`         | integer        | `vaultEntryTime` value in the response.                             |
| `followers[].lockupUntil`            | integer        | `lockupUntil` value in the response.                                |
| `maxDistributable`                   | number         | `maxDistributable` value in the response.                           |
| `maxWithdrawable`                    | number         | `maxWithdrawable` value in the response.                            |
| `isClosed`                           | boolean        | Whether the vault is closed.                                        |
| `relationship`                       | object         | `relationship` value in the response.                               |
| `allowDeposits`                      | boolean        | Whether deposits are allowed.                                       |
| `alwaysCloseOnWithdraw`              | boolean        | Whether withdrawals close positions.                                |
