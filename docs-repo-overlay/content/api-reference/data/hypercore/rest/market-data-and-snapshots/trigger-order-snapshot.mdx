# Trigger-order snapshot

Trigger orders derived from L4 state.

## Request

`POST /{apiKey}/info`

| Parameter             | Type   | Description                        |
| --------------------- | ------ | ---------------------------------- |
| `type`                | string | `triggerOrderSnapshot`             |
| Additional parameters | varies | includeUsers, includeTriggerOrders |

```json
{
  "type": "triggerOrderSnapshot"
}
```

## Response fields

| Field    | Description           |
| -------- | --------------------- |
| Response | Trigger-order records |

## Response example

```json
[]
```
