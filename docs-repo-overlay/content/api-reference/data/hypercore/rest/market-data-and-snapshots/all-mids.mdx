# All mids

Current mids keyed by asset identifier.

## Request

`POST /{apiKey}/info`

| Parameter             | Type   | Description |
| --------------------- | ------ | ----------- |
| `type`                | string | `allMids`   |
| Additional parameters | varies | dex         |

```json
{
  "type": "allMids"
}
```

## Response fields

| Field    | Description                           |
| -------- | ------------------------------------- |
| Response | Asset identifier → decimal-string mid |

## Response example

```json
{ "BTC": "0.0" }
```
