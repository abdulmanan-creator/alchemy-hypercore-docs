# User fees

Returns an account's fee schedule, current rates, and daily volume history.

## Request

`POST /{apiKey}/info`

| Parameter | Type   | Required | Description                    |
| --------- | ------ | -------- | ------------------------------ |
| `type`    | string | Yes      | Selects `userFees`.            |
| `user`    | string | Yes      | Master or sub-account address. |

```json
{
  "type": "userFees",
  "user": "0x0000000000000000000000000000000000000000"
}
```

## Response fields

| Field                                | Type            | Description                                                          |
| ------------------------------------ | --------------- | -------------------------------------------------------------------- |
| `dailyUserVlm[]`                     | array           | Daily volume entries.                                                |
| `dailyUserVlm[].date`                | string          | `date` value in the response.                                        |
| `dailyUserVlm[].userCross`           | string          | `userCross` value in the response.                                   |
| `dailyUserVlm[].userAdd`             | string          | `userAdd` value in the response.                                     |
| `dailyUserVlm[].exchange`            | string          | `exchange` value in the response.                                    |
| `feeSchedule`                        | object          | Applicable fee schedule.                                             |
| `feeSchedule.cross`                  | string          | `cross` value in the response.                                       |
| `feeSchedule.add`                    | string          | `add` value in the response.                                         |
| `feeSchedule.spotCross`              | string          | `spotCross` value in the response.                                   |
| `feeSchedule.spotAdd`                | string          | `spotAdd` value in the response.                                     |
| `feeSchedule.tiers`                  | object          | `tiers` value in the response.                                       |
| `feeSchedule.referralDiscount`       | string          | `referralDiscount` value in the response.                            |
| `feeSchedule.stakingDiscountTiers[]` | array           | `stakingDiscountTiers` value in the response.                        |
| `userCrossRate`                      | string          | Current taker rate.                                                  |
| `userAddRate`                        | string          | Current maker rate.                                                  |
| `userSpotCrossRate`                  | string          | Current spot taker rate.                                             |
| `userSpotAddRate`                    | string          | Current spot maker rate.                                             |
| `activeReferralDiscount`             | string          | Active referral discount.                                            |
| `trial`                              | object \| null  | Fee-trial details, or `null` when no trial applies.                  |
| `feeTrialReward`                     | string          | `feeTrialReward` value in the response.                              |
| `nextTrialAvailableTimestamp`        | integer \| null | Time in milliseconds when another trial may be available, or `null`. |
| `stakingLink`                        | object \| null  | Staking-link details, or `null` when no link applies.                |
| `activeStakingDiscount`              | object \| null  | Active staking-discount details, or `null` when no discount applies. |
