# User fees

Returns an account's fee schedule, current rates, and daily volume history.

## Request

`POST /{apiKey}/info`

| Parameter | Type   | Required | Description                    |
| --------- | ------ | -------- | ------------------------------ |
| `type`    | string | Yes      | Selects `userFees`.            |
| `user`    | string | Yes      | Master or sub-account address. |

```json
{
  "type": "userFees",
  "user": "0x0000000000000000000000000000000000000000"
}
```

## Response fields

| Field                                | Type   | Description                                          |
| ------------------------------------ | ------ | ---------------------------------------------------- |
| `dailyUserVlm[]`                     | varies | Daily volume entries.                                |
| `dailyUserVlm[].date`                | varies | `date` value in the response.                        |
| `dailyUserVlm[].userCross`           | varies | `userCross` value in the response.                   |
| `dailyUserVlm[].userAdd`             | varies | `userAdd` value in the response.                     |
| `dailyUserVlm[].exchange`            | varies | `exchange` value in the response.                    |
| `feeSchedule`                        | varies | Applicable fee schedule.                             |
| `feeSchedule.cross`                  | varies | `cross` value in the response.                       |
| `feeSchedule.add`                    | varies | `add` value in the response.                         |
| `feeSchedule.spotCross`              | varies | `spotCross` value in the response.                   |
| `feeSchedule.spotAdd`                | varies | `spotAdd` value in the response.                     |
| `feeSchedule.tiers`                  | varies | `tiers` value in the response.                       |
| `feeSchedule.referralDiscount`       | varies | `referralDiscount` value in the response.            |
| `feeSchedule.stakingDiscountTiers[]` | varies | `stakingDiscountTiers` value in the response.        |
| `userCrossRate`                      | varies | Current taker rate.                                  |
| `userAddRate`                        | varies | Current maker rate.                                  |
| `userSpotCrossRate`                  | varies | Current spot taker rate.                             |
| `userSpotAddRate`                    | varies | Current spot maker rate.                             |
| `activeReferralDiscount`             | varies | Active referral discount.                            |
| `trial`                              | varies | `trial` value in the response.                       |
| `feeTrialReward`                     | varies | `feeTrialReward` value in the response.              |
| `nextTrialAvailableTimestamp`        | varies | `nextTrialAvailableTimestamp` value in the response. |
| `stakingLink`                        | varies | `stakingLink` value in the response.                 |
| `activeStakingDiscount`              | varies | `activeStakingDiscount` value in the response.       |
