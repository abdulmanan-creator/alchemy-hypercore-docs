# User rate limit

A user's request-rate state.

## Request

`POST /{apiKey}/info`

| Parameter             | Type   | Description     |
| --------------------- | ------ | --------------- |
| `type`                | string | `userRateLimit` |
| Additional parameters | varies | user            |

```json
{
  "type": "userRateLimit"
}
```

## Response fields

| Field    | Description                                           |
| -------- | ----------------------------------------------------- |
| Response | cumVlm, nRequestsUsed, nRequestsCap, nRequestsSurplus |

## Response example

```json
{ "nRequestsUsed": 0 }
```
