# User role

Returns the account role and linked address where the role has one.

## Request

`POST /{apiKey}/info`

| Parameter | Type   | Required | Description                    |
| --------- | ------ | -------- | ------------------------------ |
| `type`    | string | Yes      | Selects `userRole`.            |
| `user`    | string | Yes      | Master or sub-account address. |

```json
{
  "type": "userRole",
  "user": "0x0000000000000000000000000000000000000000"
}
```

## Response fields

| Field         | Type                                            | Description                     |
| ------------- | ----------------------------------------------- | ------------------------------- |
| `role`        | user \| agent \| vault \| subAccount \| missing | Account role.                   |
| `data`        | object                                          | Response entries.               |
| `data.user`   | string                                          | `user` value in the response.   |
| `data.master` | string                                          | `master` value in the response. |
