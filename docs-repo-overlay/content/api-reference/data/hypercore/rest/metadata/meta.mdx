# Perpetual metadata

Returns perpetual market definitions and margin tiers for a selected DEX.

## Request

`POST /{apiKey}/info`

| Parameter | Type   | Required | Description                                           |
| --------- | ------ | -------- | ----------------------------------------------------- |
| `type`    | string | Yes      | Selects `meta`.                                       |
| `dex`     | string | No       | Perpetual DEX name; omit for the first perpetual DEX. |

```json
{
  "type": "meta",
  "dex": ""
}
```

## Response fields

| Field                                         | Type              | Description                                |
| --------------------------------------------- | ----------------- | ------------------------------------------ |
| `universe[]`                                  | array             | `universe` value in the response.          |
| `universe[].name`                             | string            | Name.                                      |
| `universe[].szDecimals`                       | integer           | `szDecimals` value in the response.        |
| `universe[].maxLeverage`                      | integer           | `maxLeverage` value in the response.       |
| `universe[].marginTableId`                    | integer           | `marginTableId` value in the response.     |
| `universe[].onlyIsolated`                     | boolean           | `onlyIsolated` value in the response.      |
| `universe[].isDelisted`                       | boolean           | `isDelisted` value in the response.        |
| `universe[].marginMode`                       | cross \| isolated | `marginMode` value in the response.        |
| `marginTables`                                | array             | `marginTables` value in the response.      |
| `marginTables[][0]`                           | integer           | `marginTables[][0]` value in the response. |
| `marginTables[][1].description`               | string            | Description.                               |
| `marginTables[][1].marginTiers[]`             | array             | `marginTiers` value in the response.       |
| `marginTables[][1].marginTiers[].lowerBound`  | string            | `lowerBound` value in the response.        |
| `marginTables[][1].marginTiers[].maxLeverage` | integer           | `maxLeverage` value in the response.       |

## Response example

```json
{
  "universe": [{ "name": "BTC", "szDecimals": 5, "maxLeverage": 50 }],
  "marginTables": [
    [
      50,
      {
        "description": "",
        "marginTiers": [{ "lowerBound": "0.0", "maxLeverage": 50 }]
      }
    ]
  ]
}
```
