# Spot metadata

Returns spot token and spot-pair definitions.

## Request

`POST /{apiKey}/info`

| Parameter | Type   | Required | Description         |
| --------- | ------ | -------- | ------------------- |
| `type`    | string | Yes      | Selects `spotMeta`. |

```json
{
  "type": "spotMeta"
}
```

## Response fields

| Field                    | Type           | Description                                   |
| ------------------------ | -------------- | --------------------------------------------- |
| `tokens[]`               | array          | `tokens` value in the response.               |
| `tokens[].name`          | string         | Name.                                         |
| `tokens[].szDecimals`    | integer        | `szDecimals` value in the response.           |
| `tokens[].weiDecimals`   | integer        | `weiDecimals` value in the response.          |
| `tokens[].index`         | integer        | Index.                                        |
| `tokens[].tokenId`       | string         | `tokenId` value in the response.              |
| `tokens[].isCanonical`   | boolean        | `isCanonical` value in the response.          |
| `tokens[].evmContract`   | string \| null | `evmContract` value in the response.          |
| `tokens[].fullName`      | string \| null | Full token name, or `null` when not supplied. |
| `universe[]`             | array          | `universe` value in the response.             |
| `universe[].name`        | string         | Name.                                         |
| `universe[].tokens`      | array          | `tokens` value in the response.               |
| `universe[].index`       | integer        | Index.                                        |
| `universe[].isCanonical` | boolean        | `isCanonical` value in the response.          |

## Response example

```json
{
  "tokens": [
    {
      "name": "USDC",
      "szDecimals": 8,
      "weiDecimals": 8,
      "index": 0,
      "tokenId": "0x6d1e7cde53ba9467b783cb7c530ce054",
      "isCanonical": true,
      "evmContract": null,
      "fullName": null
    }
  ],
  "universe": [
    { "name": "PURR/USDC", "tokens": [1, 0], "index": 0, "isCanonical": true }
  ]
}
```
