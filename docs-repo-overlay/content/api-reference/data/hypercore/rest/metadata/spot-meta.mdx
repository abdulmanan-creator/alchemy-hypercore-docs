# Spot metadata

Spot market metadata.

## Request

`POST /{apiKey}/info`

| Parameter             | Type   | Description |
| --------------------- | ------ | ----------- |
| `type`                | string | `spotMeta`  |
| Additional parameters | varies | —           |

```json
{
  "type": "spotMeta"
}
```

## Response fields

| Field    | Description                                 |
| -------- | ------------------------------------------- |
| Response | universe[].tokens, name, index, isCanonical |

## Response example

```json
{ "universe": [] }
```
