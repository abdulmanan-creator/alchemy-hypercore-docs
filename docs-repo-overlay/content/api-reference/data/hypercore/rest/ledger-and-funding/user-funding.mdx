# User funding

Returns a user's funding-payment history over a time range.

## Request

`POST /{apiKey}/info`

| Parameter   | Type    | Required | Description                                                       |
| ----------- | ------- | -------- | ----------------------------------------------------------------- |
| `type`      | string  | Yes      | Selects `userFunding`.                                            |
| `user`      | string  | Yes      | Master or sub-account address.                                    |
| `startTime` | integer | Yes      | Inclusive start time in milliseconds.                             |
| `endTime`   | integer | No       | Inclusive end time in milliseconds; defaults to the current time. |

```json
{
  "type": "userFunding",
  "user": "0x0000000000000000000000000000000000000000",
  "startTime": 1735689600000,
  "endTime": 1735776000000
}
```

## Response fields

| Field                      | Type   | Description                       |
| -------------------------- | ------ | --------------------------------- |
| `data[]`                   | varies | Response object.                  |
| `data[].delta`             | varies | `delta` value in the response.    |
| `data[].delta.type`        | varies | Selected read type.               |
| `data[].delta.coin`        | varies | Market identifier.                |
| `data[].delta.usdc`        | varies | `usdc` value in the response.     |
| `data[].delta.szi`         | varies | `szi` value in the response.      |
| `data[].delta.fundingRate` | varies | Funding rate.                     |
| `data[].delta.nSamples`    | varies | `nSamples` value in the response. |
| `data[].hash`              | varies | Transaction hash.                 |
| `data[].time`              | varies | Timestamp in milliseconds.        |
