# User funding

Funding payments for a user.

## Request

`POST /{apiKey}/info`

| Parameter             | Type   | Description              |
| --------------------- | ------ | ------------------------ |
| `type`                | string | `userFunding`            |
| Additional parameters | varies | user, startTime, endTime |

```json
{
  "type": "userFunding"
}
```

## Response fields

| Field    | Description     |
| -------- | --------------- |
| Response | Funding records |

```json
[]
```
