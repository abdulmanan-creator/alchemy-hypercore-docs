# Stream an L2 order book

To maintain an L2 book from `l2BookDiff`, subscribe and buffer diffs, then fetch an
`l2BookDiffSnapshot`. Discard buffered diffs whose `height` is at or below the
snapshot height. Apply the remaining diffs in height order, checking each market's
`prev_seq` against the snapshot `seq` and then against your local position.

`l2Book` is a standalone display snapshot, not a bootstrap source for a
diff-maintained book. If continuity breaks, discard affected local state and adopt
the pushed `isSnapshot: true` message.

## Cursor rule
Advance a durable cursor only after downstream storage succeeds. Treat a gap, correction, or finality change as a reason to backfill and reconcile.
