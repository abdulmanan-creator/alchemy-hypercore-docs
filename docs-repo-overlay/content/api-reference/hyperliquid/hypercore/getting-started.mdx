# Get started with the HyperCore Chain API

Use the intended chain endpoint and authentication contract to query a recent checkpoint with `hl_getLatestBlocks`, persist the last processed block height, then use batch block lookup to repair gaps.

For enriched account data and purpose-built market streams, continue with [the HyperCore Data API getting started guide](../../data/hypercore/overview.mdx).
